# Tic Tac Toe (Ruby)

A simple, command-line Tic Tac Toe game demonstrating fundamental Ruby concepts, including:

* Object-oriented programming (OOP) principles through class design.
* Basic input/output handling.
* Array manipulation for game board representation.
* Simple game logic and win condition checks.

This project was created to showcase clean, readable code and a clear understanding of basic Ruby syntax.

**How to Run:**

1.  Clone the repository.
2.  Navigate to the project directory in your terminal.
3.  Run `ruby tic_tac_toe.rb`.

This project serves as a clear example of how to translate game rules into functional code in Ruby. This project is not intended to represent my full range of software development skills.
